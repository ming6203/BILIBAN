# BILIBAN - B站用户屏蔽

Chrome 浏览器插件，用于屏蔽 B 站指定用户的评论、视频推荐、搜索结果、动态和弹幕。

## 功能特性

### 📝 核心屏蔽功能
- **评论区屏蔽**：自动隐藏被屏蔽用户的评论和回复
- **视频卡片屏蔽**：首页、搜索页、侧边推荐中隐藏被屏蔽用户的视频
- **搜索结果屏蔽**：搜索页过滤被屏蔽用户的内容
- **动态/弹幕过滤**：API 层面拦截，渲染前过滤
- **主页黑名单提醒**：打开被拉黑用户的空间主页时，自动弹窗提醒并显示所在分组

### 👥 分组与分块管理
- **黑名单分组**：将屏蔽用户按组分类，自由命名，独立开关
- **分块整理**：将相关分组打包为块，便于批量管理和云同步
- **直观管理**：弹窗界面支持对分组和分块的完全控制

### 🚀 一键操作
- **快速屏蔽**：视频卡片和评论区旁注入屏蔽按钮，点击选择分组快速添加
- **强力屏蔽模式**：高频扫描，增强屏蔽覆盖率
- **批量操作**：支持对分组的批量启用/禁用

### ☁️ 数据同步与备份
- **GitHub Gist 同步**：通过 GitHub Token 备份和同步黑名单到私有/公开 Gist
- **社区订阅**：从公开 GitHub 仓库拉取共享黑名单，自动合并更新
- **分块级同步**：可选择性地推送或拉取特定分块的数据
- **本地备份**：支持 JSON 格式的导入导出，完整保留分组结构

### 🎨 高级特性
- **Shadow DOM 支持**：完全适配 B 站 Web Components 和第三方扩展的 Shadow DOM
- **多扩展兼容**：已适配 BewlyBewly、Bilibili-Gate 等流行扩展
- **暗色模式**：自动适配系统主题，包括按钮样式
- **实时更新**：数据变更后立即生效，无需刷新页面

## 安装方法

### 从源码安装
1. **下载代码**：Clone 或 Download ZIP 本仓库
   ```bash
   git clone https://github.com/ming6203/BILIBAN.git
   ```
2. **打开 Chrome 扩展页面**：访问 `chrome://extensions/`
3. **启用开发者模式**：点击右上角的开发者模式开关
4. **加载扩展**：点击「加载已解压的扩展程序」，选择仓库目录

### 开发注意事项
- **无需构建**：纯原生 JavaScript，直接由 Chrome 加载
- **即时调试**：编辑代码后在扩展页面点击刷新按钮即可生效
- **权限要求**：需要 storage 权限保存设置，activeTab 权限进行页面交互

## 使用指南

### 基本使用
1. **打开面板**：点击浏览器工具栏的插件图标打开弹窗
2. **创建分组**：点击「+ 添加分组」，输入名称，可选择关联到现有分块
3. **添加用户**：输入 B 站用户 UID，选择分组，点击「添加」
4. **开启屏蔽**：确保分组开关为开启状态

### 分块管理
1. **创建分块**：点击「+ 添加分块」，输入名称和描述
2. **关联分组**：创建分组时选择所属分块，或在分组编辑中修改
3. **批量操作**：点击分块标题可展开/收起关联分组，支持批量开关

### 强力模式
- **启用**：点击弹窗中的「🔋 开关强力模式」
- **作用**：大幅提高扫描频率（默认 500ms 间隔），确保无限滚动页面的即时屏蔽
- **使用场景**：建议在首页、动态页等需要快速刷新的页面开启

### 快速屏蔽
- **评论屏蔽**：在评论区的用户头像旁出现的「屏蔽」按钮
- **视频屏蔽**：在视频卡片 UP 主名字旁出现的「屏蔽」按钮
- **主页屏蔽**：访问被屏蔽用户主页时，页面顶部的醒目提示

### GitHub 同步
1. **配置 Token**：
   - 生成 GitHub Token（需要 `gist` 权限）
   - 在弹窗的 GitHub 面板输入并保存
2. **创建/链接 Gist**：
   - Token 验证成功后自动创建 Gist
   - 可切换 Gist 可见性（公开/私有）
3. **分块同步**：
   - **推送**：将选中的分块数据上传到云端
   - **拉取**：从云端下载数据，可选择合并或覆盖
   - **选择性同步**：只同步需要的分块数据

### 社区订阅
1. **添加订阅源**：点击 GitHub 面板的「订阅」标签
2. **配置仓库**：输入 GitHub 仓库信息（如 `owner/repo` 路径）
   ```plaintext
   示例：example-user/shared-blacklist
   ```
3. **拉取分块**：仓库可包含多个分块文件，可选择性拉取
4. **自动更新**：定期从订阅源检查更新

### 扩展兼容性
- **BewlyBewly**：自动检测其 Shadow DOM，内部注入样式和按钮
- **Bilibili-Gate**：适配其视频卡片结构，跳过直播页干扰
- **暗色模式**：按钮样式自动适配系统的明暗主题

## API 拦截原理
### 请求过滤
插件在 `document_start` 阶段拦截所有 fetch 和 XMLHttpRequest 请求：
1. **预处理响应**：监听特定 API 端点（评论、动态、弹幕、搜索、直播等）
2. **UID 提取**：解析响应 JSON 中的用户数据
3. **条件过滤**：
   - 评论接口：过滤屏蔽用户的评论和回复
   - 动态接口：过滤屏蔽用户的动态
   - 弹幕接口：过滤屏蔽用户的弹幕
   - 搜索结果：过滤屏蔽用户的视频
4. **修改响应**：移除被屏蔽用户的数据后返回给页面

## 常见问题

### Q: 插件不生效怎么办？
A: 
1. 确认扩展已正确加载（chrome://extensions/ 中显示为已启用）
2. 确认有启用的屏蔽分组
3. 尝试刷新 B 站页面
4. 在弹窗中开启强力模式

### Q: 如何获取用户 UID？
A:
1. 打开用户个人主页，URL 中的数字就是 UID，例如 `https://space.bilibili.com/123456`
2. 用户 UID 为：`123456`
3. 插件自动识别页面中的 UID，一键屏蔽无需手动输入

### Q: GitHub 同步失败？
A:
1. 确认 Token 有 `gist` 权限
2. 检查网络连接是否能访问 GitHub
3. 确认 Gist 可见性设置正确
4. 查看浏览器控制台（F12）的错误信息

### Q: 如何迁移到新设备？
A:
1. 在旧设备导出 JSON 备份
2. 在新设备安装插件
3. 导入备份文件
4. 或配置 GitHub Token 进行云同步
